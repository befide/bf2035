---
title: Organizational Units
---

The **organizational units** schema describes all organizational units that are stakeholders with respect to the inventory.

Organizational units can be nested: each unit may have (at most) one parent.

## Fields

### Structural fields

- **id**<br/>
  Unique identifier for the organizational unit.

- **parent\_\_id** (optional)<br/>
  Identifier of the parent unit, if any.

- **topLevel\_\_id** (optional)<br/>
  Identifier of the top-level (formal) organization the unit belongs to.

---

### Common Fields

- **isPartOfCommunity** (boolean)<br/>
  Indicates whether the unit is part of the community.
- **instanceOfs\_\_taxonomyId**<br/>
  Taxonomy references describing the unit type. Possible values include: `committee`, `committee/erum-committee`, `consortium`, `department`, `funding-organization`, `research-institution`, `subdepartment`, `university`, `working-group`
- **label.fullName**<br/>
  Official, localized name of the unit (e.g., `Deutsches Elektronen-Synchrotron DESY`).
- **label.short**<br/>
  Preferred, localized short label for the unit (e.g., `DESY`).
- **tagLine**<br/>
  Concise, localized one-liner about the unit.
- **description**<br/>
  Localized description of the unit.
- **location**<br/>
  Object describing the unit's location: - **country.code**: Country code of the unit’s location. - **lat**: Latitude (for geographical visualization). - **lng**: Longitude (for geographical visualization). - **city**: City of the unit's location
- **head**<br/>
  \*(Details about the head of the unit; structure

### People (for community units only)

To determine the number of people in the community, each unit has assigned a count of individuals, categorized by three dimensions:

- **Gender:** `male`, `female`, `nonbinary`
- **Discipline:** `physics`, `engineering`, `other`
- **Career Level:** `professor`, `seniorResearcher`, `postDoc`, `phdStudent`, `masterStudent`, `bachelorStudent`

The cartesian product of these three dimensions yields **54 distinct fields** (most will be zero for a given unit).

From these 54 fields, 56 further numbers are derived;:

- A `total` is calculated from the given numbers.
- A `recursive sum` is also computed, reflecting the nested structure of organizational units.

### References

- **links.homepage** (optional) <br/>
  Localized homepage URL of the unit.
- **links.rorID** (optional) <br/>
  Research Organization Registry (ROR) identifier.
